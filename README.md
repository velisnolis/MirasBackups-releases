# Miras Backups for Joomla: releases

Update feed and installable packages of **Miras Backups** (`pkg_mirasbackups`), a Joomla 6 administrator component that shows, and lets authorised users restore, the JetBackup 5 backups of the site's hosting account through JetBackup's Socket API.

It only works on hosting servers running JetBackup 5 with the Socket API enabled for the account. The source code is maintained privately; packages are released under the GNU General Public License version 2 or later.

- Update feed for Joomla: `https://raw.githubusercontent.com/velisnolis/MirasBackups-releases/main/updates/pkg_mirasbackups.xml`
- Packages: see Releases.
